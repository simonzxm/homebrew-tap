# Simonzxm Tap

## How do I install these formulae?

`brew install simonzxm/tap/<formula>`

Or `brew tap simonzxm/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "simonzxm/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
